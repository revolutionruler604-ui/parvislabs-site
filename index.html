How we build

Kaizen, with AI in the loop

Kaizen is the practice of getting a little better every day, in small steps anyone can check. We apply it to how we work with AI. Every project runs as a loop: plan a small change, write the test that proves it, let an agent build it, review it with fresh eyes, and keep what we learned.

  1. 01
    Small batches.

    One change, one review, one merge. Small steps are easy to check and easy to undo.

  2. 02
    Prove it first.

    A failing test comes before the fix, then we break the fix on purpose to make sure the test notices.

  3. 03
    A second set of eyes.

    Work that touches money or security is checked by a different model, or a person, before it ships.

  4. 04
    Guardrails live in the system, not the prompt.

    Limits are enforced by code and hooks an agent cannot edit. A person approves every change to them.

  5. 05
    Decisions are written down.

    Every ruling is logged with its reason, so the next session, human or AI, starts where the last one stopped.

  6. 06
    Show, don't tell.

    We judge work by what it does on screen and in the numbers, not by how it is described.

What we believe

The rules every project follows

  1. 01
    Yours stays yours.

    Our tools run where you control them, on your own machine or ours, never sold, never mined. You can see what is kept and delete it any time.

  2. 02
    AI proposes. People decide.

    AI does the routine work and helps us build faster. It never makes the call, and no agent can loosen its own guardrails: a person signs off on every one.

  3. 03
    Trust is earned in practice.

    New systems run in a safe practice mode first and prove themselves before they touch anything real. Paper before live, a few households before many.

  4. 04
    Every number has a source.

    Figures come from code and evidence, tested before they ship, never from a guess. If we cannot show where a fact came from, we do not state it.

  5. 05
    Balance over growth.

    We would rather be steady than fast. Calm software, sustainable pace, and room for the life the work is meant to serve.

  6. 06
    Small on purpose.

    One person and a capable partner can build with care. We stay small enough to know everyone who uses what we make.
